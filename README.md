# kids-web-dev-landing-2026

A playful, responsive landing page for a kids' web development course (HTML, CSS & JavaScript, 2026 Guide). Built with a hand crafted "crayon box" visual style: a mock code editor hero, language trading cards, a level based learning journey, parent testimonial bubbles, and a fully linked header and footer. Pure HTML and CSS, no build step, deploys straight to GitHub Pages.

## Live sections

- Hero with a playful mock code snippet
- Three language cards for HTML, CSS and JavaScript
- A three level "Explore, Build, Launch" learning journey
- A blog callout linking to the full 2026 guide
- Parent testimonial bubbles
- Final call to action and footer with all site links

## Run locally

Just open `index.html` in a browser. No dependencies, no build tools.

## Deploy on GitHub Pages

1. Push this repo to GitHub.
2. Go to Settings > Pages.
3. Set the source branch to `main` and the folder to `/root`.
4. Your page will be live at `https://<your-username>.github.io/kids-web-dev-landing-2026/`.
